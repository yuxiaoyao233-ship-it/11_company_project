# 工业设备故障诊断多Agent系统 (MVP版)

## 📖 项目简介

本项目是一个面向工业制造企业的轻量级设备故障诊断系统。针对传统人工排查效率低、通用大模型易产生幻觉（胡说八道）的痛点，采用**LangGraph 多智能体协作架构**与**双引擎知识库（向量+图谱）**，实现从工人模糊描述到专业维修方案的全自动生成。

## 🏗️ 技术架构

- **核心框架**: LangChain + LangGraph (状态流转与多Agent编排)
- **大模型 (LLM)**: 支持本地 Ollama (Qwen2.5-3B) 或 云端 DeepSeek API (通过 .env 切换)
- **知识库 (双引擎)**:
  - 向量库: ChromaDB + nomic-embed-text (历史相似案例语义召回)
  - 图谱库: NetworkX (设备故障实体关系推理)
- **后端服务**: FastAPI + Uvicorn
- **前端展示**: 原生 HTML + JS + marked.js (单页轻量级交互)

## 🚀 核心工作流

1. **预处理智能体**: 将口语化描述转结构化 JSON（提取设备、现象、严重程度）。
2. **异常识别智能体**: 提取特征，并行调用向量库（检索历史）与图谱库（推理根因）。
3. **根因分析智能体**: 结合双引擎结果，综合分析最可能的故障原因。
4. **维修方案智能体**: 生成包含步骤、备件、安全事项的标准作业指导书(SOP)。

## 🛠️ 本地启动指南

1. 安装依赖: `pip install -r requirements.txt`
2. 配置环境变量: 根目录新建 `.env` 文件，写入 `DEEPSEEK_API_KEY=sk-xxxxxxx`
3. 启动后端服务: `uvicorn backend.api:app --host 127.0.0.1 --port 8000 --reload`
4. 访问系统: 浏览器打开 `http://127.0.0.1:8000`
